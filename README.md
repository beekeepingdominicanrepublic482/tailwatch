Install the plugin on your WordPress site using the file you just downloaded.

6. Click Install Now.
7. Click Activate Plugin after the process completes.

## 🆘 Troubleshooting common issues

If you encounter errors, check these areas first:

*   **Plugin Conflict:** Deactivate other security plugins before running Tailwatch. Two security plugins often conflict and cause errors.
*   **File Permissions:** Ensure your server allows the plugin to write files. Check your hosting support docs if you see error messages about file writing.
*   **Memory Errors:** Increase your PHP memory limit to 512MB if the scan stops midway. Contact your host if you need help with this setting.
